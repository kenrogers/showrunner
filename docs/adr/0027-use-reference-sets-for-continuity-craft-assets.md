# Use Reference Sets for continuity craft assets

Showrunner will group continuity References into Reference Sets instead of treating every Reference as a flat one-off image.

A Reference Set can belong to a Production, Scene, or Shot and can require typed References such as character sheets, wardrobe sheets, prop scale sheets, environment plates, style frames, first frames, last frames, or return frames.

This follows practical AI filmmaking workflow: durable character sheets, prop scale references, environment plates, and shot frame references are what let generated Shots preserve identity, scale, continuity, and editability across a complete Production.
