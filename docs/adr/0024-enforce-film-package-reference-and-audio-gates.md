# Enforce film-package, reference, and audio gates

Showrunner will treat AI-video best practices as production gates, not prompt-writing advice.

Before paid video generation, every continuity-critical Shot must have a Film Package and at least one usable Reference image asset. Video requests are built from the Film Package continuity lock, Shot intent, motion, camera, narration context, and dialogue context.

Before Final Review can pass, a Production with Narration must have generated narration audio for every narration beat. Assembly and Export are not enough to call a Production complete.

This keeps Showrunner aligned with the production workflow we want: write the film, define continuity, create/attach references, animate controlled shots, then mix sound and export.
